## 무슨 뜻인가

**들었다면** — 시험지가 소단원명을 안 적어 줘서 트랙 G 가 본문·학년·학기·회차로
**추정해 붙인** 행이다. 실측 정확도 **90%**(편 단위 5겹 교차검증)이므로
**4,158행 중 약 416행은 엉뚱한 소단원에 실려 있다.** 진도와 안 맞는 문항이 나왔다면
이 배정이 틀렸을 가능성이 크다. **고치는 방법은 덮어쓰기다** — 나중에 그 시험지의
소단원이 적힌 판본이 나오면 그쪽이 이긴다(힌트 기반 매핑은 실측 96.3%).

**안 들었다면** — 시험지가 적어 준 소단원을 그대로 쓴 행이다(1차 적재분 6,042 등).
다른 원인을 봐야 한다. 후보: 1차 보고 §9.2 의 **형제 쏠림**(트리가 더 잘게 쪼개져 있어
`일차부등식의 활용(개수, 예금액, 유리한 방법)` 한 곳으로 몰림), 트랙 G §5.1 의
**본문↔라벨 어긋남 56건**, §5.2 의 **학년 오배정 163건**.

## 왜 DB 가 아니라 파일인가

`Problem` 에 «추정으로 붙였다» 를 적을 칸이 **없다**(트랙 G 결정 시트).
스키마를 바꾸지 않기로 했으므로 **이 파일이 유일한 기록이다.**

| | |
|---|---|
| 목록 | `scripts/qa/handoff/load2-external-ids.json` (커밋됨) |
| 행 | **4,513** (그중 자동 출제 자격 4,158 · 정답없음 334 · 출제보류 21) |
| 담긴 것 | `externalId` → `unitId` · `confidence` · 시험지 학년 |
| 입력 corpus | `346b5894c606b4c9` (트랙 D 10:00 재추출본 — 1차 적재분과 같다) |
| 적재 | 2026-08-17 · `problem` 42,639 → 47,152 |
| 판정 근거 | 트랙 G `track-g-classify.md` · A안 · 학년별 문턱 90% |

**이 파일을 지우면 어느 행이 추정인지 답할 수 없고, 되돌릴 수도 없다.**
