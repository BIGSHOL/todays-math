너는 **그림 검수**의 **두 번째 시선**이다. 파일을 만들거나 고치지 마라. git 도 건드리지 마라.
답만 말한다.

붙인 이미지는 검수 시트 한 장이다. 짝이 6개 있고, 한 짝은
**왼쪽이 래스터(정본), 오른쪽이 SVG(다시 그린 것)** 이며 왼쪽 끝에 4자리 번호가 있다.

앞선 검수가 **놓치는 것**이 있어서 네가 한 번 더 본다. 그러니
**「괜찮아 보인다」로 넘어가지 마라.**

## 방법 — 짝마다 이 순서로 해라
1. 래스터에 있는 것을 **하나씩 세어라**: 선분 몇 개, 글자·숫자 무엇무엇,
   화살촉 몇 개, 눈금·점·짧은 표시 몇 개, 칠해진 면 몇 개, 무늬(해칭·격자·점무늬) 유무.
2. 그 목록을 **SVG 에서 하나씩 찾아라.**
3. 못 찾은 것이 있으면 그것이 결함이다.

특히 **작고 눈에 안 띄는 것**을 일부러 찾아라 —
선의 **끝**에 붙은 짧은 표시, 아주 작은 글자·아래첨자, 면 **안쪽**의 무늬,
여러 면 중 **한 면만** 다른 칠, 그림 **가장자리**에서 잘린 것.

## 결함이 **아닌** 것 (이걸 결함이라 하면 멀쩡한 그림을 버린다)
- SVG 가 더 또렷하거나 선이 더 가는 것 — 정상이다(벡터니까)
- 래스터의 워터마크·얼룩이 SVG 에 없는 것 — SVG 가 더 낫다
- 글꼴 모양·자간이 조금 다른 것
- 여백·크기·위치가 조금 다른 것
- 색이 조금 진하거나 연한 것

🔴 그래도 **확실하지 않으면 결함이라고 하지 마라.** 「래스터에는 X 가 있는데 SVG 에는
   없다」를 한 줄로 못 적겠으면 그건 결함이 아니다.
🔴 6짝을 하나도 빠뜨리지 말고 전부 판정해라.

## 답하는 형식 (이 형식 말고 아무 말도 하지 마라)

짝마다 한 줄씩 6줄:
```
<4자리번호> OK
<4자리번호> 결함 <래스터에는 무엇이 있는데 SVG 에는 없다>
```
