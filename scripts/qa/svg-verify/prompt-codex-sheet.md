너는 **그림 검수**만 한다. 파일을 만들거나 고치지 마라. git 도 건드리지 마라.
답만 말한다.

붙인 이미지는 검수 시트 한 장이다. 짝이 6개 있고, 한 짝은
**왼쪽이 래스터(정본), 오른쪽이 SVG(다시 그린 것)** 이며 왼쪽 끝에 4자리 번호가 있다.

두 그림을 견주어 **SVG 가 래스터의 내용을 잃었는지** 판정해라.

## 결함으로 볼 것
- 획이 빠졌다 (선분·화살표 머리·눈금·해칭·점)
- 글자가 빠졌거나 깨졌다 (꼭짓점 이름·치수·축 이름·각도·단위)
- **칠(채움)이 빠졌다** — 실제 사례: 원뿔 세 토막 중 한 토막만 칠이 없다
- **잘렸다** — 실제 사례: 좌표축의 x·y 이름과 화살표가 잘렸다
- **전혀 다른 그림이다** — 실제 사례: 래스터는 원 안 O·A·B·C 인데 SVG 는 내접사각형
- 삽화(사진 같은 그림)가 검은 덩어리로 뭉갰다

## 결함이 **아닌** 것 (헷갈리지 마라)
- SVG 가 **더 또렷한 것** — 정상이다(벡터니까)
- SVG 의 **선이 더 가는 것** — 전반적으로 그렇다. 내용이 있으면 통과
- 래스터에 **워터마크·얼룩**이 있고 SVG 에 없는 것 — SVG 가 더 낫다
- 글꼴 모양이 조금 다른 것
- 여백·크기가 조금 다른 것

🔴 **확실하지 않으면 결함이라고 하지 마라.** 지어낸 결함 한 건은 멀쩡한 그림을
   버리게 만든다. 「무엇이 어떻게 다른가」를 한 줄로 못 적겠으면 그건 결함이 아니다.
🔴 6짝을 **하나도 빠뜨리지 말고** 전부 판정해라.

## 답하는 형식 (이 형식 말고 아무 말도 하지 마라)

짝마다 한 줄씩 6줄:
```
<4자리번호> OK
<4자리번호> 결함 <무엇이 어떻게 다른가 한 줄>
```
