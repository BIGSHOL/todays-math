수학 문항 해설 생성 작업이다. 학원 시험지 해설지에 인쇄될 물건이라 정확성이 전부다.

아래 JSON 배열의 각 문항을 직접 풀어라. 계산을 검산해라. content 의 $...$ 는 KaTeX 수식이다. \overline{34} 같은 표기는 순환소수 순환마디다. 보기(①~⑤ 또는 1.~5.)가 있으면 객관식이다.

각 문항에 대해 다음 중 하나의 객체를 만들어라:
- 풀 수 있으면: {"id": "...", "finalAnswer": "최종 답 — 객관식이면 보기 번호를 ①~⑤ 로, 그 외에는 값 자체(LaTeX 허용)", "solution": "한국어 해설 — 수식은 $...$ 인라인 KaTeX, 풀이 단계 사이는 개행(\n), 마크다운 금지, 3~6줄로 간결하게, 값을 지어내지 마라"}
- 본문만으로 풀 수 없으면(그림·표가 필요한데 없다, 본문이 깨져 있다, 조건이 모자란다): {"id": "...", "skip": "짧은 사유"}

DB 에 기록된 정답은 모른다 — 독립적으로 풀어라. 틀리면 통째로 버려지니 정확하게 풀어라.

solution 문자열에서 $...$ 로 감싼 수식 구간의 개수는 반드시 짝수여야 한다(여는 $ 를 빠뜨리면 렌더가 깨진다). 특히 "\mathrm{A}(1, 2)" 같은 점 좌표 표기를 쓸 때 그 앞에 여는 $ 를 빠뜨리는 실수가 잦다 — 모든 인라인 수식은 반드시 $ 로 열고 닫아라.

결과는 입력과 같은 순서의 JSON 배열 **하나만** 출력하라. 마크다운 코드펜스(```)나 그 외 설명 텍스트는 절대 출력하지 마라 — 순수 JSON 텍스트만.
