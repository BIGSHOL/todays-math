# Agent Lifecycle 규칙

생성 조건:
- 작업이 5개 이상의 파일을 포함할 때
- 병렬 작업이 가능할 때 (06-tasks.md 병렬 실행 테이블 참조)
- 전문화가 필요할 때 (backend/frontend/database/test)

종료 조건:
- 3회 연속 잘못된 제안
- 컨텍스트 윈도우 > 85%
- 순환 편집 감지됨

이 프로젝트 참고:
- 디자인 게이트(`[협의 필요]`) 상태의 UI 태스크는 에이전트를 생성하지 않는다 — 원장님 협의가 선행
- T5.1(지면 디자인)은 에이전트 태스크가 아니라 원장님과의 협의 태스크다
