## 2. 중복 방지 원장 — **재이관 전 반드시 대조**

### 2.1 본문 해시 원장
`scripts/qa/imported-content.txt` — 이미 DB에 있는 문항의 **본문 해시**(sha1 앞 16자리,
공백 정규화 후). 재이관 시 이 해시에 있으면 **건너뛴다**.

재생성: `node scripts/qa/build-import-ledger.mjs`

### 2.2 externalId — 재이관 멱등 키 (2026-08-14 신설, 최우선)
`selectMissingLoadRows`는 `externalId`가 있으면 **내용 대조보다 먼저** 그것으로 중복을 거른다.
내용 대조 키(`loadRowKey`)는 `answer`를 포함하는데 정답 백필로 기존 행의 answer가
바뀌었기 때문에, 내용만 보면 같은 문항을 '새 것'으로 오인해 중복 삽입한다.

### 2.3 ⚠️ 기존 `problemFingerprint`를 중복 판별에 쓰지 말 것
`src/lib/import/problemFingerprint.ts`의 지문은 `answer`/`solution`을 포함한다.
**2026-08-14 정답 백필로 2,400여 건의 지문이 바뀌었다.** 같은 원본을 재이관하면
지문이 안 맞아 **중복 삽입된다**. 중복 판별은 §2.1 본문 해시로 한다.

### 2.4 OCR 품질 감사 원장
`scripts/qa/ocr-audit-clean.txt` — 결함 검사를 통과한 문항 해시.
`node scripts/qa/ocr-audit.mjs` 는 이 원장에 있는 문항을 **재검사하지 않는다**.
검사 세트를 바꾸면 스크립트의 `CHECKSET_VERSION`을 올린다(원장 자동 무효화).

적재하도록 고쳤다 — `externalId`(UNIQUE) · `sourceFile` · `school` · `subject` ·
`examId` · `questionNumber` · `score`.
마이그레이션 `20260814120000_add_problem_source_metadata`.
**이제부터 이관되는 문항은 원본으로 되짚을 수 있다.** 기존 9,197건은 값이 NULL이므로
재추출로만 채울 수 있다.

## 4. 토큰 절약 원칙 (대량 데이터 작업 공통)

에이전트가 데이터를 컨텍스트로 읽으면 토큰이 폭증한다. 아래를 지킨다.

1. **스캔·집계는 스크립트가 한다.** 화면(대화)에는 요약 수십 줄만 출력하고,
   문항별 상세는 파일로 떨군다. (예: `ocr-audit.mjs` → 9,197건 스캔, 출력 10줄)
2. **파일 in / 파일 out.** 서브에이전트에게 JSON 파일 경로를 주고 결과도 파일로 쓰게 한 뒤,
   최종 응답은 `done total=60 high=57 …` 한 줄만 받는다. 문항 본문이 오케스트레이터
   컨텍스트에 절대 올라오지 않는다.
3. **원장으로 재작업을 막는다.** 통과분·처리분 해시를 남겨 다음 실행에서 건너뛴다.
4. **대용량 산출물은 커밋하지 않는다.** 상세 리포트 JSON은 `.gitignore`
   (`scripts/qa/reports/*.json`), 원장(수십 KB)만 커밋한다.
5. **배치 출력은 분할한다.** 서브에이전트 1회 응답이 64k 출력 토큰을 넘으면 실패한다
   (2026-08-14 실제 발생). 60건 배치는 20건씩 3파일로 나눠 쓰게 한다.

## 5. 앞으로 기출을 추가 이관할 때 (권장 절차)

1. `scripts/qa/nfile-inventory.txt.gz` 에서 대상 파일을 고른다(재스캔 금지).
2. 추출 스크립트가 파일 → JSON 으로 변환한다. **처리한 원본 경로를 결과에 함께 기록한다.**
3. 적재 전 §2.1 본문 해시와 대조해 이미 있는 문항은 제외한다.
4. 적재 후 `node scripts/qa/build-import-ledger.mjs` 로 원장을 갱신한다.
5. 처리한 원본 파일 경로를 `scripts/qa/imported-files.txt` 에 누적 기록한다(파일 단위 중복 방지).

### hwp/pdf 처리 메모
- 원본의 76%가 PDF, 21%가 HWP다. HWP는 `개인/기출/HWP 2 PDF`(2,099개)처럼
  변환본이 이미 있는 경우가 있으니 **변환 전에 기존 변환본 유무를 먼저 확인**한다.
- 그림이 포함된 문항은 이관해도 DB에 이미지 필드가 없어 사용 불가다(→ `docs/planning/07` D-37 참조 예정).
