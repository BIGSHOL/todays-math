# 🔴 정정 (2026-08-20) — 아래 「전량 1,576」은 **사실이 아니다**

이 보고서의 §0·§1 은 Grok 세션이 「1,576자리 전량을 눈으로 봤다」고 적었다.
**검산해 보니 아니다.** 그 세션이 낸 결함 6건을 하나씩 확대해서 대조했더니:

**독립 확인이 갈라 줬다.** `1193` 은 시트 51에 있는데, 그 구간을 따로 훑은

## 3. 깨끗했던 것 · 막지 않은 것

0001–0140 전량(140장)은 꼭짓점 이름·치수·화살표 머리·눈금·직각 표시·채움·3D
숨은선이 남아 있었다. 뒤 구간에서 결함으로 올린 것 말고는 같은 모양이었다.

막지 않은 차이:

- SVG가 래스터보다 또렷한 것 — 벡터라 정상.
- 글꼴 모양이 조금 다른 것 — 내용은 같다.
- 표 머리 베이지/회색 — 숫자·글자가 같다.
- **0510** 경사면 왼쪽 사람이 컬러에서 **검정 실루엣**으로 바뀌었다. A·B·C·15°·200m·직각은 있다. 「채움이 까맣게 뭉갠」 부류에 가깝지만 푸는 데 쓰는 도형은 남아 있어 차단하지 않았다.
- **1197** 점 G의 마커가 정본은 검은 점, SVG는 작은 사각형처럼 보인다. 위치·24cm·G'는 같다.

일관된 차이 하나: SVG 선이 래스터보다 **가늘고 연하다.** 내용 누락이 아니라
원본 획 굵기로 보이지만, 종이에서 흐릴 수 있다 — 실물 검수 항목이다.

## 4. 막힌 171자리 — SVG가 틀린 건가, 래스터가 틀린 건가

**둘 다 있다. 일괄 되살리면 안 된다.**

| 막힌 n | 판정 |

`0141`(6.73%)이 시험지에 나간다. **2%가 필요하다.**

되살릴 수 있는 것은 「같은 그림+여백」과 「래스터가 지문을 삼킨 것」뿐이다.
그건 이 32장 안에서도 소수다. 나머지 139장은 안 봤다.
