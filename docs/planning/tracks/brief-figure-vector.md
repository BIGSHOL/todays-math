# 그림 벡터 트랙 — 작업 지시서 (워크트리 `그림벡터` / 브랜치 `feat/figure-vector`)

> 같이 읽을 것: `docs/planning/tracks/figure-quality-brief.md` (§4 ㉠ · §9 · §12 · §13 · §15)
> 그 문서가 이 트랙의 배경이다. **§13 은 §9 의 잘못을 정정한 것이니 §13 을 믿어라.**

## 0. 이 트랙이 맡는 것 — 둘이다

### ㉮ **그림 칸 원장(rect ledger)을 만든다** — 지금 아무 데도 없다

`figure-manifest.json` 에 `rect` 키가 **0건**이다. RPM 의 `source_coords` 는
발문 상자이지 그림 칸이 아니다. 그림 칸은 `map-figures.py` 의 `map_exam()` 과
`crop-rpm-from-pdf.py` 의 `figure_rect()` 가 **런타임에 만들고 그대로 버린다.**

그래서 지금은 「이 그림이 원본 지면에서 몇 mm 였나」를 아무도 모른다. 그 값이 없으면

- 300dpi 재크롭도 (§3 ①),
- 인쇄 물리 크기도 (§14, 다른 트랙),
- 벡터 SVG 의 목표 크기도 (§9)

전부 못 한다. **이 원장이 그림 트랙 전체의 병목이다. 이것부터 끝내라.**

### ㉯ **벡터인 그림은 SVG 로 뽑는다** (§4 ㉠ · §12)

RPM 은 표본 100.0% 가 벡터, 기출은 8.5% 가 벡터다. 이 무리는 다시 자를 필요 없이
**해상도 개념이 사라진다.** 약 2,900장(18%)이 대상이다.

## 1. ㉮ 그림 칸 원장 — 규격

산출물: `scripts/qa/reports/figure-rect-ledger.json`

그림 파일 **한 장당 한 줄**로, 아래를 적는다. 못 구한 항목은 **`null` 로 적고 세어서
찍는다** — 조용히 빼지 마라(이 저장소에서 「N passed」가 분모를 안 말해 준 사고가 있다).

| 키 | 뜻 |
| --- | --- |
| `figure` | `public/figures` 기준 상대 경로 (예: `2658/q13.png`) |
| `source_pdf` | 원본 PDF 절대 경로. 디스크에 **실제로 있는지** 확인해 `source_exists` 로 따로 적는다 |
| `page` | 원본 쪽 번호 (0-based 인지 1-based 인지 키 이름에 박아라) |
| `rect_pt` | `[x0, y0, x1, y1]` — PDF 좌표(pt) |
| `width_mm`, `height_mm` | `rect_pt` 폭·높이 / 72 * 25.4 |
| `native_xref` | 그 칸이 **삽입 이미지로 잡히는가**(true) / **클립 렌더 폴백인가**(false) |
| `kind` | `vector` / `raster` — §12 의 기준(드로잉 덩어리 vs 삽입 이미지)으로 판정 |
| `current_px` | 지금 `public/figures` 에 있는 파일의 실제 픽셀 `[w, h]` |
| `note` | 못 구한 사유. 「없다」를 적을 때는 **무엇을 보고 없다고 했는지** 함께 적어라 |

### 어떻게 구하나

- **다시 매핑하는 수밖에 없다**(§13). `map-figures.py` 의 `map_exam()` 과
  `crop-rpm-from-pdf.py` 의 `figure_rect()` 를 **그대로 불러라.** 규칙을 옮겨 적지 마라 —
  옮겨 적는 순간 원장과 실제 크롭이 갈라지고, 갈라져도 아무도 모른다.
- 두 함수가 지금 rect 를 반환하지 않고 버린다면, **버리지 않고 돌려주도록 최소한으로**
  고쳐라(기존 호출부의 동작은 바뀌면 안 된다 — 기존 테스트가 초록인지 확인).
- 편 목록·경로는 기존 스크립트가 이미 아는 곳에서 가져와라. 새로 손으로 적지 마라.

### 🔴 먼저 재서 보고할 것 (원장님이 「① 비용부터 재라」 하셨다)

원장을 다 만들기 전에, **작은 표본으로 비용부터 재서 보고서에 적어라.**

1. **분모** — 그림 16,122장이 몇 편의 원본 PDF 에서 왔나. 그중 **디스크에 실제로 있는
   것이 몇 편**인가. 없는 편은 몇 장의 그림을 물고 있나.
2. **시간** — 편 10개를 실제로 돌려 재고, 전량을 **선형 외삽**하라.
   외삽값에는 반드시 「10편 실측 × N」이라고 근거를 적어라. **추정치를 사실처럼 쓰지 마라.**
3. **네이티브 vs 폴백 비율** — §15. `extract-all-figures.py` 는 `stat["클립 렌더"]`·
   `"xref 못찾음"` 를 **올리기만 하고 안 찍는다.** 세기만 해라(파일은 쓰지 마라).
   ⚠️ **확장자로 나누지 마라** — JPEG 는 대개 네이티브지만 PNG 는 섞인다.
4. **못 재는 것** — 못 잰 것은 못 잰다고 적어라. 이게 가장 중요하다.

## 2. ㉯ 벡터 → SVG

- `page.get_svg_image()` 는 **쪽 전체**를 뽑는다(실측 615KB · path 529개 · 배경 이미지
  포함). cropbox 로 안 잘린다. **`get_drawings()` 로 그 rect 안의 path 만 골라 SVG 를
  새로 짜라.**
- 선 굵기·글자 크기는 **엔진 정본으로 정규화**한다. 이 저장소에 엔진이 들어와 있다:
  `vendor/figure-engine/core/figure_svg.py` — `type_scale(vb_w, vb_h, role)`,
  실선 `1.4` / 보조선 `1.0` / 화살·눈금 `1.2`, 글꼴 `Times New Roman, Batang, serif`.
  **호출부에서 숫자를 손으로 적지 마라.** (2026-08-13: 손으로 적어서 한 그림 안에
  점 이름 15 · 각도 11 · 치수 12.5 가 됐다.)
- 크기는 §9 규격: `목표 인쇄 폭(mm) = min(70, rect 폭(pt)/72*25.4)`. 이제 ㉮ 원장이
  그 값을 준다.
- **원본과 겹쳐 대조하라.** 좌표를 옮기는 일이라 틀리면 도형이 통째로 어긋난다.
  200dpi 로 렌더한 원본 크롭과 새 SVG 를 같은 크기로 그려 픽셀 차이를 세라.
  **차이가 크면 버려라** — 판정은 버리는 쪽으로 기운다.

## 3. 🔴 이 저장소에서 반드시 지킬 것

1. **`git add -A` 금지.** 다른 오르카 세션이 같은 저장소를 쓴다. **경로로만** 스테이징하고,
   커밋은 만들자마자 하라(스테이징한 채로 두면 남의 커밋에 실려 나간 전례가 두 번 있다).
2. **공유 DB(D-31) 에 쓰지 마라.** 이 트랙은 **읽기만** 한다. 굳이 써야 하면 반드시
   `ALLOW_SHARED_IMPORT=1` 게이트를 두고, **되돌리기 원장을 DB 보다 먼저** 쓰고,
   `git check-ignore -q <파일>` 이 **exit 1**(=커밋된다)인지 확인하라.
   `scripts/qa/reports/` 는 **디렉터리째 무시**되므로 `.gitignore` 에 `!` 줄이 필요하다.
3. **제자리 덮어쓰기 금지.** 새 디렉터리에 만들고 견준 뒤 바꿔치기한다.
   `public/figures` 의 기존 파일을 지우거나 덮지 마라.
4. **원본 PDF·N드라이브는 읽기만.**
5. **한컴(HWP) COM 을 쓰지 마라** — 원장님 화면 포커스를 뺏는다(절대 규칙 9).
6. **`fs.rmSync` 금지** — 경로에 한글이 있으면 노드가 **메시지 없이** 죽는다.
   `noRmSync.test.ts` 가 막는다.
7. TS 를 건드리면 TDD(RED→GREEN). `npm run lint`·`npm run type-check` 를 커밋 전에
   직접 돌려라(훅을 믿지 마라 — 새 워크트리에서 훅이 조용히 안 돌던 전례가 있다).

## 4. 이 저장소가 여러 번 데인 함정 (읽고 시작해라)

- **판정의 «참»이 우리가 고치려는 그 데이터에서 오면 안 된다.** 손상된 값을 기준으로
  삼으면 손상이 심할수록 수리가 막힌다 — 이 저장소에서 일곱 번 났다.
- **문턱을 여러 번 고치게 되면 문턱이 아니라 축이 틀린 것이다.** 열쇠를 바꿔라.
- **가드는 망가뜨려 봐야 가드인 줄 안다.** 넣은 검사를 하나씩 변이시켜 **빨개지는지**
  확인하라. 안 빨개지면 장식이다.
- **표본을 눈으로 봐라.** 이 저장소의 결함은 거의 전부 눈으로 봐서 나왔다.
- **「N개 통과」는 N이 전부인지 말해 주지 않는다.** 분모를 먼저 지켜라.
