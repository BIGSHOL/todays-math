## 3. 결론 — 축은 유효, «장치»가 모자란다

우리 축(절차 → 문장 한 겹 → 두 단계 → 역산)은 교재 사다리와 방향이 같다.
그러나 **교재가 난이도를 올리는 장치**는 우리 파일럿보다 다양하다:

1. **소문항 계단 유무** — 같은 사슬(둘레→변→넓이)이 개념응용에선 (1)(2) 계단으로,
   실력·최상위에선 계단 없이 나온다. **계단을 빼는 것 자체가 한 단계**다.
2. **관계 서술로 치수 주기** — 「세로가 가로보다 3m 짧은」·「아랫변이 윗변보다 4cm 더 길 때」.
   수를 직접 안 주고 관계로 준다.
3. **단위 섞기·환산 결합** — 700cm×2m, 500cm 정사각형과 6m 직사각형 비교.
4. **배열 곱** — 타일 N개×M줄 (곱셈 결합).
5. **겹침·복합 도형 + 넓이 관계 조건** — 최상위 S 의 뼈대.
6. **논증 서술형** — 잘못 말한 것을 찾아 이유를 쓰고 고친다.
7. **돌아간 도형** — 기울여 그리기(그림 장치. 렌더러에 회전 각 지원 필요).
8. (아래층) **공식 빈칸·모눈 세기** — 우리 «연산» 아래. 하위반 배려에 쓸 층.

**우리 파일럿 «심화»는 교재 눈금으로 개념응용~실력 수준이다.** 원장님이 말한
「고난이도」(최상위급)까지 가려면 심화 갈래에 장치 ①②⑤를 조합해야 한다.
단, 4단은 확정(D-71)이므로 **단을 늘리지 않고 갈래 안에서 장치를 다양화**한다.
