# 트랙 B — 정답 대조와 잔여 정답

`docs/planning/tracks/README.md` 의 공통 규칙을 먼저 읽어라. 그 규칙이 이 문서보다 우선한다.

## 왜 하나

이 정답은 **학생 시험지에 그대로 인쇄된다.** 우리는 정답 없는 문항을 AI 로 6,000건 넘게
풀어 채웠고, 검증은 오랫동안 AI 끼리 교차 검증이었다. 같은 모델이 같은 실수를 하면 못 잡는다.

2026-08-15 에 **완료본 PDF 뒤쪽에 학교가 인쇄한 공식 정답면이 통째로 들어 있다**는 걸 발견했다
(2,263편 중 2,242편 = 99%, 그중 96% 가 텍스트로 읽힌다). `10-handoff.md §2.4` 의
"정답은 완료 PDF 에 없다" 는 전제가 틀렸던 것이다.

**공식 정답이 있으면 그게 정본이다.** AI 풀이는 공식 정답이 없을 때만 쓴다.
실측 사례: AI 계산 `a=-3, b=2` ↔ 공식 정답 `a=-1, b=16/9`.

## 현황

`scripts/qa/reports/answer-audit.json` (`npx tsx scripts/qa/audit-answers-vs-official.ts` 로 재생성):

| 갈래 | 건수 | 상태 |
|------|------|------|
| 번호끼리 어긋남 | 0 | 48건 교정 완료 |
| **값 형태 불일치** | **1,019** | 미처리 |
| **빈 정답인데 공식엔 있음** | **62** | `--fill` 뒤에 보류 |
| 정답면 없음 | 21편 | 미조사 |
| final-pairs 미연결 | 9편 | 미조사 |
| DB 에 정답 없음 (전체) | 532 | 미조사 |

## 할 일

### B-1. 값 형태 불일치 1,019건 — 표기 차이와 진짜 오답을 갈라라

표본을 보면 `4` ↔ `k=4`, `x²` ↔ `x2`, `cm²` ↔ `cm2`, `⑴ 5, ⑵ 4` ↔ `⑴ 5 ⑵ 4` 처럼
**답은 같은데 표기만 다른 것이 다수**다. `audit-answers-vs-official.ts` 의 `normalize()`
가 일부를 흡수하지만 부족하다.

순서: (1) 1,019건을 규칙으로 분류해 표기 차이를 걷어낸다 → (2) 남은 것만 실제 판정.
**AI 를 1,019건에 무작정 돌리지 마라.** 규칙으로 90% 가 걷힌다면 남는 건 100건 안쪽이다.

⚠️ **이전 회차에 정확히 거꾸로 된 가드를 넣었다.** "한 시험지에 어긋남이 몰리면 정답면
정렬이 밀린 것이니 교정에서 뺀다" 고 했는데, 조사해 보니 몰린 48건이 **전부 진짜 DB 오답**
이었고 안 몰린 2건이 내 추출 버그였다. 그대로 적용했으면 맞는 답을 틀리게 바꾸고 틀린 답은
남길 뻔했다. **몰림은 조사 단서일 뿐 배제 근거가 아니다.**

**표기를 어느 쪽으로 통일할지는 원장님 결정 사항이다** (지면에 인쇄되는 형식이라서).
분류까지 하고, 통일 규칙이 필요하면 후보 2~3안을 예시와 함께 코디네이터에게 올려라.

### B-2. 빈 정답 62건

공식 정답면의 수식이 텍스트 레이어에서 평문으로 뭉개진다 — `√⁄5`(분수 가로선 잔존),
`80또는-104`(공백 유실), `a2+b2`(위첨자 소실). 그대로 인쇄하면 틀린 값이 나간다.
`extract-official-answers.py` 는 이미 PUA 역변환을 한다 (`pua_table.json`).
그 뒤에도 남는 훼손이라 **글리프 좌표(위첨자 판정)나 clip 렌더 이미지**를 봐야 할 수 있다.
복원이 안 되면 억지로 채우지 말고 그대로 두고 폐기 후보로 넘겨라.

### B-3. 정답면 없음 21편 + final-pairs 미연결 9편

미연결 9편: `4418 4465 5207 5319 5532 5610 5842 5891 5924`.
원본 PDF 를 직접 열어 정답면이 정말 없는지, 아니면 `ANSWER_PAGE`/`PROBLEM_PAGE` 판정에
걸러진 것인지 확인해라. 규칙을 넓힐 때는 **`extract-official-answers.py` 주석의 실패 5개**
(PUA / 접두어 / 지면 내 순서 / 문제 지면 오검출 / 구분자 필수)를 먼저 읽어라. 그 다섯을
다시 열면 진짜 정답이 가짜에 덮인다.

### B-4. 정답 없는 532건 전수

어느 출처에서 왔고 왜 비었는지 분류해라. 원본에서 회수 가능한 것과 그렇지 않은 것을 가른다.
**AI 로 풀기 전에 이관 코드를 먼저 의심하라** — 지난 여섯 결함이 전부 이관 단계 유실이었다.

## 완료 기준

- 1,019건이 「표기 차이 N / 진짜 오답 M / 판정 불가 K」로 갈렸는지.
- 진짜 오답은 공식 정답으로 교정(dry-run → 보고 → `--apply`).
- 정답 없는 532건이 「회수 가능 / 불가」로 갈렸는지.
- `answer` 외의 컬럼은 건드리지 마라.
