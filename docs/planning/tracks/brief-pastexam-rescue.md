## 1. 이미 밝혀진 것 — **다시 조사하지 마라**

- 그림 유실 174행 중 **167행의 원본이 지금도 N드라이브에 있다**(123편 · HWP 78 · PDF 45).
  나머지 7행은 `sourceFile` 자체가 없다(2026-08-14 이전 이관분) — **불가**.
- ⚠️ **「대장에 없다」를 「원본이 없다」로 읽으면 틀린다.** `figure-manifest.json` 은
  **PDF 오려내기**가 만든 것이라 HWP 정본만 있는 편은 애초에 안 들어간다.
  실제로 확인하니 58편이 **전부 살아 있었다**. 원본 존재는 **`problem.source_file` 로**
  묻고 **드라이브를 직접 stat** 해라.
- **회수 경로는 PDF 좌표가 아니라 HWP 정본의 BinData** 다. HWPX 는 `<hp:pic>` 이
  문단 흐름 안에 있어 **어느 문항의 그림인지 문서 구조로 정해진다** — 오려낼 것이 없다.
  §4.2 에 명령 6줄이 그대로 있다.
- 정렬은 **DB 본문 ↔ HWP 발문**을 직접 맞춘다(한글+숫자 2-gram Dice).
  최고점만 보면 형제 문항에 붙으므로 **버금과 0.12 이상 벌어질 때만** 맞다고 본다.
  검산: 86행의 HWP 순번이 **86/86 전부 DB 문항번호와 같았다** — 본문과 독립인 근거다.

## 2. 할 일

1. **㉠ 그림 74건** — 위 표의 「다음 수」를 위에서부터 실제로 해 본다.
   42행(벡터 획)이 가장 크다. **17행(그리기 개체)은 `render-vector-figures.py` 가 있다.**
2. **㉡ 본문 오염 35건** — HWP 정본 본문으로 갈아 끼운다. 2026-08-16 트랙 D 의
   교체 판정을 그대로 쓰되 **그 절의 「가드 다섯 개가 거꾸로 걸렸다」를 먼저 읽어라.**
   ⚠️ **오염 마커가 잡히면 그 오염이 부풀린 길이 가드를 끈다.** 그리고
   **경계를 확실히 못 자르는 오염은 지우지 말고 막아라** — 지우면 근거가 사라진다.
3. **㉢ 표 3건** — HWP 표 구조에서 되살린다. 되살린 표를 **눈으로** 봐라.
4. **㉣ HWP 19건** — 6건은 `sourceFile` 이 `.PDF` 다. `final-pairs.json`(2,950짝)으로
   짝 HWP 를 찾고, 대장에 없으면 **파일명 열쇠로 드라이브를 직접 훑어라.**
5. **㉤ 보기 그림 짝 43건** — 원본 지면 텍스트 레이어에 ①②③④⑤ 가 **좌표째로** 있다
   (2026-08-18 에 97/147 을 이 길로 회수했다). 43건은 그 길이 못 닿은 것이니
   **HWP 쪽에서** 다시 물어라 — HWPX 는 그림이 문단 흐름 안에 있다.
   ⚠️ **출처가 다른 두 증거가 어긋나면 «자동»을 주지 마라.**
6. **㉥ 미분류 20건** — 표본을 보면 전개도·가로등 그림자다. **대부분 그림이 필요 없다.**
   판정기에 반영하거나 오탐 목록에 넣어라. 조용히 넘기지 마라.

## 3. 반드시 지킬 것

1. **판정기는 반대쪽 모집단에 전량 대 봐라.** 「그림이 **붙어 있는** 행에 같은 규칙을
   대면 «불필요»가 나오면 안 된다」처럼 **반증 가능한 형태**로 물어라.
   2026-08-18 에 이 검사가 22건을 찾았다.
2. **규칙을 고쳤으면 고치기 전에 확인한 표본부터 다시 봐라.**
3. **되돌리기 원장을 DB 보다 먼저 쓰고 `git check-ignore -v <파일>` 로 확인.**
   `scripts/qa/reports/` 처럼 **디렉터리 자체를 무시하면 안쪽 `!` 예외가 안 먹는다.**
4. **같은 컬럼을 두 스크립트가 잠근다** — `directUseAllowed` 는 그림 유실과 보기그림
   양쪽이 쓴다. 상대 원장에 이미 있는 행은 안 잠그고, 되돌릴 때는 **지금 값이 자기가
   쓴 값일 때만** 되돌려라.
5. **파괴적 작업에는 «무엇을 잃는가»를 같이 세라**(D-20). 건수만 보면 다 그럴듯하다.
6. **적용할 컬럼마다 전량을 봐라.** `content` 에서 전량 확인한 규칙이 `solution` 에서
   깨진 적이 있다.

## 4. 하지 말 것
