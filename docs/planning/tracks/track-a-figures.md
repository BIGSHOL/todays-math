# 트랙 A — 그림 연결과 정밀도

`docs/planning/tracks/README.md` 의 공통 규칙을 먼저 읽어라. 그 규칙이 이 문서보다 우선한다.

## 왜 하나

문제은행 36,597건 중 **본문이 그림을 명시적으로 가리키는데 그림이 없는 문항이 1,620건**이다.
그림 없는 도형 문제는 학생이 풀 수 없다. 지금 폐기 후보 515건 중 285건이 "그림 없음" 이다 —
이 트랙이 성공하면 폐기 후보가 그만큼 줄어든다.

판정 기준은 프로젝트 다른 검사와 같은 엄격한 표현만 본다 (`scripts/figure/map-figures.py`
의 `FIGURE_WORD`). '그래프'·'도형' 만으로 세면 "이차함수의 그래프는…" 이 걸려 기준이 부푼다.

## 할 일

### A-1. 695건 재연결 — **여기부터. 토큰 0 이고 가장 크다**

매니페스트에 그림이 있는데 DB `figureUrls` 가 비었다. **먼저 왜 안 붙었는지 밝혀라.**
적재 순서 문제인지(`scripts/import/final-batch.ts` 의 `resolveFigures` 가 도는 시점),
매니페스트가 나중에 커진 것인지, 번호 표기가 어긋나는지(`String(Number(...))` 정규화).
원인을 모르고 재연결만 하면 다음 적재에서 같은 구멍이 다시 난다.

재연결 전 **`public/figures/` 에 파일이 실제로 있는지 확인**하고, 없는 경로는 붙이지 마라.
깨진 이미지는 그림 없음보다 나쁘다.

### A-2. 96건 — map-figures 재현율

시험지는 매니페스트에 있는데 해당 번호에 그림이 안 잡혔다. 표본 10건을 PDF 에서 직접 보고
원인을 분류해라: 벡터 도형이라 이미지 블록이 아닌 경우 / 줄머리 `N.` 인식 실패 /
본문은 "그림과 같이" 인데 실제로 그림이 없는 경우(원본 결손). 마지막 갈래는 회수 불가이니
폐기 후보로 넘긴다. `scripts/figure/probe-vector-figures.py` 와
`diagnose-missing.py` 가 이미 있다 — 새로 만들기 전에 읽어라.

### A-3. 4편 — 매니페스트 자체가 없음

`map-figures.py` 를 그 4편에 직접 돌려 실패 사유를 보라. PDF 손상인지 경로 문제인지.

### A-4. RPM 814건

`scripts/qa/recover-rpm-figures.ts` 가 sumaek `diagram_assets` 에서 1,071장을 회수했다.
남은 814건이 그 테이블에 정말 없는 것인지, 조회 키가 안 맞는 것인지 확인해라.
**트랙 C 가 `externalId` 를 채우면 회수 키가 늘어난다** — C 의 진행을 코디네이터에게 물어보고,
아직이면 sumaek 본문 대조로 붙는 것만 먼저 처리해라.

### A-5. 정밀도 — 그림 2장 이상 663건

past_exam 663건에 그림이 2장 이상 붙었다. 매니페스트 기준으로는 926문항이 2장 이상이다.
좌표·순서 매칭이 **인접 문항의 그림까지 끌어왔을** 가능성이 크다.

**정밀도가 재현율보다 중요하다.** 엉뚱한 그림이 붙은 문항은 정답이 틀린 것보다 눈에 띄고,
학원 신뢰를 직접 깎는다. 표본 20건을 실제로 렌더해 눈으로 확인하고, 오배치율이 유의미하면
매칭 규칙을 조이되 **조인 뒤에도 재현율이 얼마나 떨어지는지 함께 보고**해라.

## 완료 기준

- 「그림언급 O · 그림 ✗」이 past_exam 802 → 몇, transformed 814 → 몇 으로 줄었는지 숫자로.
- 표본 20건 육안 검증 결과 오배치율.
- 재연결 도구는 dry-run 기본 + `ALLOW_SHARED_IMPORT=1` 게이트. 커밋할 것.
- `figureUrls`·`figureSource` 외의 컬럼은 건드리지 마라.
