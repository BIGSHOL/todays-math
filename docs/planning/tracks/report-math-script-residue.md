## 어떻게 찾았나 — 「라벨을 세다가」

원장님이 종이에서 「`AH` 가 이탤릭」이라 하셔서 기하 라벨을 세는 계량기를 만들었다.
그런데 1위가 `AB`(2,203)가 아니라 **`LEFT`(10,111)** 였다. 기하 라벨이 아니라
**HWP 수식 스크립트가 날 글자로 남아 있는 것**이었다.

**세는 열쇠를 「이탤릭」에서 「대문자 덩어리」로 넓히지 않았으면 못 봤다.**
지금까지의 잔재 지표는 **`content` 만** 재고 있었고, 거기서는 0.31% 였다.

## 왜 「빈 분수」가 가장 나빴나

`src/lib/math/textPreprocess.ts` 가 `\frac{}{b}` → **`\frac{0}{b}`**,
`\frac{a}{}` → **`\frac{a}{1}`** 로 바꾸고 있었다. KaTeX parse error 를 막으려던
밴드에이드인데, **들어온 자료에 대고 쓰면 숫자를 지어낸다.**

기출 `HAL0201-V6WW` 보기 ①은 `87\frac{}{2}` — 정답은 **87/2** 인데 종이에는
**`87·0/2`** 로 찍혔다. `J30503-LNCC` 는 보기 ②③④⑤가 **전부** 그랬다.

KaTeX 는 `\frac{}{4}` 를 **붉게** 표시한다. 즉 결함이 **스스로 신고할 수 있었는데**
그 밴드에이드가 신호를 지우고 그럴듯한 숫자를 넣고 있었다. 이제 **□** 로 남긴다.

## 분자는 «잃은 것»이 아니라 «분수 밖에 남은 것»이었다

`87\frac{}{2}` 에서 87 은 바로 옆에 있다. 그래서 **바깥 자료 없이** 되살아난다.
다만 **어디까지 끌어오나**가 위험한 자리다:

* 윗자리 연산자가 없는 한 덩어리면 자동 (`2\sqrt{5}\frac{}{5}` → `\frac{2\sqrt5}{5}`)
* **합의 한 항이면 자동으로 안 한다** — 평균 `120/10` 이 `…+4/10` 이 된다.
  그럴듯한데 틀린 값이라 아무도 못 알아챈다.
* 그 12자리는 **본문 밖 근거로 검산**하고 손으로 켰다:

| 문항 | 근거 |
| --- | --- |
| `HAL0208-UWT3` | α=7π/4 에서 (sinα−cosα)/tanα=√2 → 기록된 **정답 ④** |
| `J30503-TA3N` | tanA=1/2 에서 값 2 → 기록된 **정답 ④** |
| `J10306-AYT8` | 해설 다음 줄이 `-3a+20=-27a+27` |
| `HPS0302-ZDPT` | 해설 다음 줄이 `a+b+1=2m` |
| `J30701-Q87W` | 합이 120, 해설이 `=12` |
| `HAL0212-GNR8` | cos D=−1/3 · AC²=17 · CD=2 → (AD²−13)/(4AD) |

* 분자가 **아예 없는** 5문항(`lim` 문항)은 되살릴 수 없어 출제에서 뺐다.
  그냥 두면 `\frac{□}{t-1}` 이 학생 시험지에 나간다.

## ⇒ 를 전부 바꾸면 안 된다

`\Rightarrow` 981자리 중 **밖 451자리는 진짜 함의**다
(`명제 q ⇒ p` · `0.3x>2.4 ⇒ x>8`). **`\lim` 아래첨자 안 530자리만** 바꿨다 —
거기서는 ⇒ 가 성립할 수 없다. 밖은 손대지 않았다.

## 정본 변환기도 샌다 (검산으로 드러난 것)

`testchanger/core/hwpeq_to_latex.py` 를 실제 토큰으로 통과시켜 보니:

| 넣은 것 | 나온 것 | 판정 |
| --- | --- | --- |
| `rarrow` | `\Rightarrow` | ⇒ 는 →가 아니다 |
| `OVERLINE {AB}` | `\frac{}{LINE}AB` | **선분이 분수가 된다** |
| `rm overline {AH}` | `\mathrm{over}lineAH` | 깨진다 |
| `RIGHTARROW`·`rightarrow`·`leftarrow` | 날 글자 그대로 | 안 바뀐다 |
| `{n} choose {r}` | `nchooser` | 안 바뀐다 |
| `0.3 DOT` | `0.3\dot{}` | 순환마디를 잃는다 |

**전부 에러가 안 난다.** 해설 4,213행을 이 변환기로 그냥 돌리면 안 되는 이유다 —
먼저 이 구멍들을 막는 겉포장과, 「고친 뒤에도 잔재가 남았나」를 세는 가드가 필요하다.
