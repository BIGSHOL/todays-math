# 그림 인쇄 크기 트랙 **2차** — 실측값으로 보이게 (워크트리 `그림인쇄`)

> 1차 지시서: `brief-figure-print-size.md` · 1차 보고서: `report-figure-print-size.md`
> 1차는 **지면이 mm 를 받을 준비**까지 했다. 2차는 **원장님이 실물로 판단하실 수 있게**
> 만든다. **DB 는 이번에도 안 건드린다.**

## 0. 왜 2차가 필요한가

1차의 전후 비교 지면(`/dev/figure-print-size`)은 정직하게 적어 둔 대로 **mm 가 가정값**이다
(「우리가 200dpi 로 잘랐다」는 기록에서 환산). 그런데 실측으로는 **84% 가 네이티브**라
그 가정이 틀린다. 가정값을 보고 원장님이 판단하시면 **실제와 다른 것을 판단하시게 된다.**

**이제 실측 원장이 있다.** `그림벡터` 트랙이 원본 PDF 를 다시 매핑해 만들었고,
이 워크트리에 이미 들어와 있다:

```
scripts/qa/reports/figure-rect-ledger.json     (gitignore — 커밋되지 않는다)
```

- 16,119행 = `public/figures` 파일 전량. `width_mm`/`height_mm` 이 있는 행이 **14,391**.
- 그림마다 **증명 경로**가 다르다: 원본 바이트 md5 10,656 · 픽셀 치수 2,017 ·
  원본 지면 겹쳐 대조 1,025. `note` 에 적혀 있다.
- 못 구한 2,421건도 **사유별로** 들어 있다(HWP BinData 1,444 · RPM 자리 600 등).

이 값으로 전량을 재 봤다 (`python scripts/qa/measure-figure-size-change.py`):

| | 지금 규칙 | 새 규칙 |
| --- | ---: | ---: |
| 폭 중앙 | **70.0mm** | 48.6mm |
| 70mm 상한에 걸린 것 | **82.3%** | 17.8% |
| | 작아진다 78.2% · 그대로 21.2% · 커진다 0.6% · 배율 중앙 **×0.73** | |

⚠️ 1차가 표본 6장으로 낸 「일률 ×0.48」은 **가정값 탓에 과장된 값**이었다.

## 1. 할 일

### ㉮ `/dev/figure-print-size` 가 **실측 원장**을 읽게 한다

- **DB 도 스키마도 건드리지 마라.** 이 화면은 개발용이므로 원장 JSON 을 직접 읽어라.
- 원장이 없으면 **「원장이 없다」고 화면에 적고 멈춰라.** 조용히 가정값으로 되돌아가지
  마라 — 그러면 다음 사람이 실측을 보고 있다고 착각한다.
- 화면에 그림마다 **그 mm 가 어떻게 증명된 값인지**(바이트/픽셀/겹쳐 대조) 적어라.
  근거의 세기가 다르면 원장님 판단도 달라진다.

### ㉯ 표본을 **고르지 말고 분포에서 뽑아라**

1차의 6장은 손으로 골랐다. 그러면 「가장 큰 실데이터」가 안 들어와 레이아웃이 깨지는
조건이 지워진다(2026-08-19 범위 피커 사고와 같은 자리). 아래를 **모두** 넣어라:

1. **배율 분포**에서 고르게 — 하위 5% · 25% · 중앙 · 75% · 상위 5% 근처에서 각 2~3장
2. **15mm 미만이 되는 53장 전량** — 이게 이 변경의 유일한 위험이다
3. **커지는 85장**에서 몇 장
4. **mm 를 모르는 그림**(2,421건)이 아는 그림과 **한 지면에 섞인** 모습 — 실제 지면이
   그렇게 나간다. 어색한지 봐야 한다
5. 세로로 긴 그림 · 한 문항에 여러 장 붙은 문항

### ㉰ 「작아서 못 읽는가」를 **숫자로도** 보여라

원장님이 종이로 보시는 것이 최종 판정이지만, 그 전에 세어서 좁혀 드려라.

- 새 규칙에서 **15mm 미만 53장 · 10mm 미만 3장**이 무엇인지 목록을 뽑아라.
  실제로 그 그림들이 무엇인가(글자가 있나, 눈금이 있나, 아니면 단순 도형인가)?
- **바닥값(예: 최소 15mm)을 두는 선택지**가 값어치가 있는지 세어 보고 보고서에 적어라.
  두면 몇 장이 영향을 받고, 그때 일관성은 얼마나 깨지나?
  ⚠️ 결정하지 마라 — 원장님이 정하실 일이다. **선택지와 그 대가를 세어서** 올려라.

### ㉱ 인쇄 매체 갈무리를 다시 떠라

`docs/design/mockups/figure-print-size-print.png` 를 실측값으로 갱신.
헤드리스 Chromium 으로 떠라 — **원장님 화면 포커스를 뺏지 마라**(절대 규칙 9).

## 2. 🔴 하지 말 것

1. **DB·`schema.prisma` 금지.** 1차 보고서가 짚은 대로, 스키마에 먼저 넣으면 컬럼 없는
   공유 DB 에 `SELECT` 를 쏴서 **인쇄가 통째로 죽는다.** 마이그레이션 적용은 원장님
   확정 뒤에 할 일이다.
2. **`git add -A` 금지.** 다른 세션이 같은 저장소를 쓴다. 경로로만 스테이징하고
   커밋은 만들자마자 하라.
3. `scripts/figure/`·`public/figures*` 금지 — 다른 세션 자리.
4. **`status` 를 「통과」로 바꾸지 마라.** 실물 검수는 원장님이 하신다(절대 규칙 6).
5. `fs.rmSync` 금지(한글 경로에서 노드가 조용히 죽는다).

## 3. 완료 조건

1. `/dev/figure-print-size` 가 **실측 원장**을 읽고, 원장이 없으면 그렇게 **적고 멈춘다.**
2. 표본이 §1 ㉯ 의 다섯 갈래를 **모두** 담는다.
3. 15mm 미만 53장의 목록과 **그것들이 무엇인지** 본 결과가 보고서에 있다.
4. 바닥값 선택지의 대가가 숫자로 적혀 있다(결정은 안 한다).
5. 인쇄 갈무리 갱신.
6. 보고서 `report-figure-print-size.md` 에 2차 절을 더한다. **못 한 것·못 잰 것**을 따로.
7. `npm run lint` · `type-check` · `test` 를 **직접** 돌린다.
