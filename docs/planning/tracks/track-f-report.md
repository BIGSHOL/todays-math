### 2.1 한글 서명은 **행이 아니라 편으로** 봐야 갈라진다

행 단위 235건은 진짜 중복과 문구 우연 일치가 섞여 있다. 학교가 다른
`삼각형 ABC에서 … 외접원의 반지름의 길이는?` 류가 숫자만 다른 채 같은 서명을 갖기 때문이다.
전체 본문 유사도로도 안 갈라진다 — 기존 DB 행은 PDF 텍스트 레이어라 **같은 문항인데
서식이 달라** 0.85 근처로 떨어지고, 거기에 템플릿 형제가 겹친다.

**편 단위 겹침률로 보면 깨끗하게 갈라진다.**

| 겹침률 | 편 | 실체 |
|---|---|---|
| 50~64% | **4** | 진짜 중복 |
| 20~50% | **0** | (비어 있다) |
| ≤12% | 125 | 문구 우연 일치 (겹친 행 130) |

가운데가 비어 있어 기준값(0.3)을 어느 쪽으로 움직여도 판정이 안 바뀐다.

### 2.2 걸린 4편 — 같은 시험지가 다른 `examId` 로 이미 있다

원본 경로까지 확인했다. 학교·학년·회차·출판사가 같고 **과목 표기만
`수하`↔`공수2`(= `HIGH_SUBJECT` 별칭)** 로 다르다.

### 3.3 워터마크 186행 — 트랙 D 규칙이 **줄 단위라 놓친다**

`stripWatermark` 는 줄 전체가 워터마크일 때만 지운다. 그런데 정규분포표처럼 표가 있는
문항에서는 셀에 붙어 나온다:

```
$\mathrm{P}(0\leq Z\leq z)$대구광역시 내신 수학 연구회
```

문구가 한 종류뿐이라는 건 트랙 D 가 이미 확인했으므로 **줄 가운데 것도 지웠다**.

`\S{0,20}` 로 봐서 **이름에 공백이 있으면 안 잡힌다**.

> 트랙 D 소유 파일은 고치지 않았다. 트랙 F 쪽 `sanitizeContent` 에서만 처리했다.
