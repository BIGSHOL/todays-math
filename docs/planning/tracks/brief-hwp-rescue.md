## 2. 할 일

### ㉠ 236편 전량 추출

`scripts/qa/extract-hwp-all.py` 가 이미 있다 — **재개 가능하고 실패를 3회까지 센다.**
`final-pairs.json` 을 입력으로 쓴다. 편당 약 12.8초(COM), 4프로세스 병렬이 실측으로
안전하다(2026-08-15). 236편이면 병렬로 15분 안쪽이다.

- 대장에 없는 20편은 **경로를 직접 확인**해서 별도 목록으로 만든다.
- `.hwpx` 는 `scripts/qa/reports/hwpx/` 에 남긴다(이미 103편 있다 — 다시 안 만든다).
- **N: 은 네이버 MYBOX 라 중간에 끊긴다.** `wait_mount` 이 이미 있다.

### ㉡ 258 문항을 대조해 **실제 회복 건수를 센다**

문항 번호 대응이 첫 함정이다 — `parse_exam` 의 `number` 는 **미주 순서**지
시험지 번호가 아니다. 그러니 번호만 믿지 말고 **본문 유사도로 맞대라.**
(2026-08-16 트랙 D 가 같은 자리에서 가드 다섯 개를 거꾸로 걸었다 —
그 절을 반드시 먼저 읽어라.)

판정은 **양쪽 비교**로 한다. 한쪽 값의 절대 크기(짧다·한글이 적다)로 가르지 마라.

## 3. 하지 말 것

- **공유 DB 를 한 건도 쓰지 마라** (D-31). 이 트랙은 **측정**이다.
  적용 스크립트는 만들어도 되지만 게이트(`ALLOW_*`) 뒤에 두고 **드라이런까지만.**
- **`(완료)` 표기가 아닌 원본에서 뽑지 마라** (D-37).
- **제품 코드를 고치지 마라.** R1(렌더러)·R2(파서)는 원장님 확정 대기다.
- `git add -A` 금지 — 다른 세션이 같은 저장소를 쓴다. **경로로만 스테이징.**
