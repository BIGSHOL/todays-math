## 0. 디자인 작업 방식 (확정)

이 프로젝트의 디자인 협업 규칙 — **이 섹션만은 확정 사항입니다:**

0. **목표는 회피가 아니라 정체성이다 (2026-08-13 원장님 지시).** "정형화된 AI 생성 툴처럼
   보이지 않는 것"은 최소 조건일 뿐, 진짜 목표는 **오늘의수학만의 특색 있는 틀** — 첫눈에
   구별되는 비주얼 정체성이다. 이를 위해 **첫 UI 구현(T1.2) 전에 '디자인 정체성 세션'을
   선행**한다: 서로 방향이 다른 시안 2~3안(실제 화면 목업)을 제시 → 원장님이 방향 선택 →
   그 방향의 문법(색/타이포/형태/밀도)을 이 문서에 확정 기록 → 이후 모든 화면이 그 문법을
   따른다. 참고 후보: 원장님이 직접 설계한 eywa의 "Editorial 7문법"
   (`C:\Creative\eywa\docs\design-conventions.md` — de-mono, 폰트 두께 2종 제한, 알약 통일,
   WCAG 대비 치트시트)은 원장님 취향의 실증 사례로서 방향 후보 중 하나가 될 수 있다.
1. **AI 공장식 스타일 전면 배제.** 다음은 금지 목록입니다:
   - 보라/파랑 그라데이션 히어로, 유리morphism 카드
   - shadcn/ui 등 기성 컴포넌트 킷의 기본 모양 그대로 사용
   - 목적 없는 이모지·아이콘 남발
   - 화면마다 반복되는 동일한 카드 그리드 레이아웃
   - "AI가 만든 것 같은" 뻔한 인상을 주는 모든 관성적 선택
2. **컴포넌트는 Tailwind CSS로 직접 제작** (D-15). 기성 킷 미사용.
3. **결정 프로세스 — Wire → Hi-fi 2단계, 각 4~5안 (2026-08-13 원장님 지시, 확정)**:
   - ① **Wire 단계**: 구조/레이아웃 와이어프레임 **4~5안** 제시 → 원장님 선택
   - ② **Hi-fi 단계**: 선택된 구조 위에 시각 디테일(색/타이포/형태/질감) **4~5안** 제시 → 원장님 선택
   - ③ 확정 내용을 이 문서에 기록 후 구현 착수. **확정 전 구현 금지.**
   - ④ **세부 디테일(간격·문구·버튼 위치·아이콘 유무 등)은 항상 질문** — 사소해 보여도
     추정으로 확정하지 않는다.
4. **이 문서는 살아있는 문서**: 협의 결과가 나올 때마다 `[협의 필요]` → `[확정]`으로 갱신.

### 1.1 핵심 가치 (방향 합의됨, 세부는 협의)

## 6. 접근성 체크리스트

### 6.1 필수 (MVP)

- [ ] **색상 대비**: 텍스트와 배경의 대비율 4.5:1 이상
- [ ] **포커스 링**: 키보드 탐색 시 포커스 표시 명확
- [ ] **클릭 영역**: 버튼/링크 최소 44x44px
- [ ] **에러 표시**: 색상만으로 구분하지 않음 (텍스트 병행)
- [ ] **폰트 크기**: 화면 본문 최소 14px, 시험지는 인쇄 가독성 별도 검증

### 6.2 권장 (v2)

- [ ] 키보드 전체 탐색 가능
- [ ] 스크린 리더 호환 (ARIA 라벨)

### 6.3 마우스 어포던스 `[확정 — D-30]`

손가락(pointer)과 행/카드 hover는 **눌러지는 컨트롤의 신호**다. 신호가 거짓이면 버그다.

- 손가락: 활성 버튼, `a[href]`, 셀렉트, 라디오/체크만
- 금지 커서: `disabled` / `aria-disabled`
- 화살표: 반 카드 본체, 대장부 행, 학년 칸, 학생 이름, 게이지, 문제 카드
- 반 선택은 행 전체가 아니라 이름 버튼만
- 구현 게이트: `globals.css` 전역 규칙 + `src/lint/scanAffordance.mjs` (ESLint/테스트/커밋)

## 8. 확정 기록 (협의 완료 항목)

### 8.1 S-03 메인 화면 구조 `[확정 — 2026-08-13 Wire 세션]`

Wire 5안(A~E) 중 A(오늘 스택)+E(대장부 표) 결합안으로 확정:

- **자동 전환**: 오늘 처리할 일이 남아 있으면 **A 스택 상태**, 전부 완료되면 **E 대장부 표 상태**로 자동 전환
- **우측 진도 입력 패널 상주** (두 상태 모두) — 수업 직후 10초 입력 + 이번 주 통계
- 차시 이동: `< 차시이동 >`. 단원 트리는 반 화면(S-07)에서 직접 선택
- 세부 장치 3종 채택: ① ⇄ 수동 전환 토글 ② 스택 하단 완료 반 한 줄 요약 ③ 표에 "내일 테스트" 열 (자동 준비 예약 표시)
- 시각 스타일(색·타이포·질감)은 Hi-fi 세션에서 별도 확정

### 8.2 수업 카드 단계 표시기 `[확정 — 2026-08-13 원장님 지시]`

- 모든 수업 카드는 **동일 위치에 4단계 파이프라인 표시기**를 갖는다: `진도 → 출제 → 검수 → 인쇄`
- 단계가 진행될수록 **같은 자리의 라벨이 전진**한다 (완료 단계는 채움, 현재 단계는 강조, 미래 단계는 흐림) — 카드들을 훑으면 각 반이 어디까지 왔는지 진행감이 느껴져야 함
- **주 버튼은 항상 현재 단계의 동사 하나**: "진도 입력" / "검수" / "인쇄" — 단계가 넘어가면 버튼도 바뀐다
- 단계 표시기의 시각 표현(도장/체크/세그먼트 등)은 선택된 Hi-fi 방향의 문법을 따른다

### 8.3 시각 방향 `[확정 — 2026-08-13 Hi-fi 세션]`

- **H5 "스위스 계기판"** 채택: 뉴트럴 그레이 스케일 + 단일 강조색, 강한 그리드, 큰 순번 숫자,
  tabular 숫자, 직각, 장식 0. 단계 표시기는 4칸 세그먼트 게이지
- **열맞춤 필수 (원장님 지시)**: 카드 내부는 고정 컬럼 그리드 — 번호·반 정보·단계 게이지·주 버튼이
  모든 카드에서 **동일한 x좌표**에 정렬. 정보 길이가 달라도 컬럼이 밀리지 않는다 (줄바꿈 대신 말줄임)

### 8.5 시험지 지면 `[확정 — 2026-08-14 T5.1]`

화면 UI(H5 스위스 계기판)와 시험지 지면은 목적이 다르므로 문법을 맞추지 않는다.
지면은 학생·학부모가 매일 보는 얼굴이다.

**베이스**: Mathgen `JaseupTemplate` (자습). Hi-fi는 H1 원본 금색.

| 항목 | 확정 |
|------|------|
| 종이 | 따뜻한 흰 `#FCFCF8` (`paperWarm`) |
| 액센트 | 금색 `#A57F00` |
| 본문 폰트 | 명조 (`PAPER_FONTS.serifKR`). 라벨·학원명은 sans (`Pretendard`) |
| 수식 | KaTeX Computer Modern |
| 영문 라벨 | 유지 (`SELF-STUDY`, `SCRATCH PAD`) |
| 학원명 | 좌측 상단 작은 금색 「오늘의수학」 (`SELF-STUDY` 위) |
| 학습일 | 우측 상단. 값은 테스트 예정일 |
| 이름칸 | 학습일 아래 한 줄 `이름 ________ · 반 ______` |
| 제목 | `{테스트유형} · {소단원}` 예: `일일테스트 · 일차부등식` |
| 오늘의 목표 | 제목 아래 한 줄. 단원/출제 메타에서 채움 |
| 핵심 개념 박스 | **일일·확인 모두 첫 장에 항상**. 금색 좌측 5px 바 |
| 문항 번호 | `문 N` (금색 명조 18px) |
| 배점 | **없음**. 일일/확인테스트는 점수가 아니라 맞은 개수 / 전체 개수 |
| 내 정답 · 채점 | 문항마다 밑줄 + 체크 칸 |
| 풀이 | 우측 16px 모눈 (`SCRATCH PAD`). 1단 그리드 `1.15fr / 1fr` |
| 밀도 | 장당 2문항. 8문항 일일 = 문제지 4장 (풀이 공간 우선) |
| 이어지는 장 | 간소 헤더 `오늘의수학 · {제목}` + `p. N`. 개념 박스 없음 |
| 하단 | `오늘의 메모` 점선 + `p. N` |
| 여백 | Mathgen 자습 그대로 (첫 장 padding 36/50, 본문 padX 50) |
| 정답지 | 같은 금색 자습 얼굴. 빠른 정답 그리드 + 2단 해설. 번호는 `문 N` |

**이식 범위 (T5.2)**: `JaseupTemplate` + 공통 `BodyContainer`/`ProblemBody`/`printPack` + 정답지.
헤더에 학원명·이름/반 한 줄을 얹는다. 배점(`PointsLabel`)은 이 지면에서 그리지 않는다.
나머지 5템플릿(평가원/정통/모던/워크북/유형)은 가져오지 않는다.

**참조 시안**:
- 확정 합성: `docs/design/mockups/print-t51-jaseup-final.html`
- 베이스 6안: `docs/design/mockups/print-t51-templates.html`
- Hi-fi 5안: `docs/design/mockups/print-t51-jaseup-hifi.html`

**T5.2로 넘기는 실물 검수**: 명조 가독성, 모눈 농도, 여백, 수식 깨짐, 4장 스테이플.

### 8.7 '오늘의 시험' 서브 탭 `[확정 — 2026-08-15 T7.0 Wire]`

기출 예상 점수 판독기를 얹는 새 축. **반·진도 단위로 도는 '오늘의 수학'과 축이 다르다** —
'오늘의 시험'은 **학교 내신 1회차**를 단위로 돈다. 그래서 서브 탭으로 가른다.

#### 탭 위치 — **워드마크 분기** 채택

```
오늘의수학 │ 오늘의시험    8월 15일 금   남은 작업 3
─────────   ‾‾‾‾‾‾‾‾‾‾
                          메인   반   문제은행
```

- 워드마크 자리에 두 제품명을 나란히. **선택된 쪽 검정 굵게 / 나머지 회색.**
- 날짜·남은 작업 크롬은 **두 탭이 공유**한다.
- 클릭 시 전체 화면이 갈린다(별도 라우트).
- 반려안: nav 항목 추가(무게감 약함), 상단 2단 크롬(세로 공간 소모).

#### 진입 구조 — **회차 계기판** 채택

진행 중인 내신 회차를 **큰 순번 숫자 + D-day**로 나열한다(§8.3 계기판 문법 그대로).

```
진행 중인 내신                        [+ 새 회차]
──────────────────────────────────────────────────
01   정화중 3학년  25-2 중간              D-14
     청사진 ✔   문제지 ✔   채점 3/12   실점수 —
     근거 4회차 · 신뢰도 0.62

02   경명여중 2학년  25-2 중간            D-21
     청사진 ✔   문제지 —   채점 —      실점수 —
     근거 2회차 · 신뢰도 0.34
```

- 행마다 **4단계 파이프라인**: `청사진 → 문제지 → 채점 → 실점수`.
  §8.2의 "같은 자리에서 라벨이 전진한다" 규칙을 그대로 따른다(수업 카드와 같은 문법).
- **근거 회차 수와 신뢰도를 행에 노출한다.** 예측기는 근거가 적으면 못 맞힌다 —
  그 사실을 숨기지 않는 것이 이 화면의 핵심 계약이다(11 §2.1·L1 evidenceCount/confidence).
- 신뢰도가 낮으면 행에 경고를 단다(⚠ 근거 부족). 색은 G2 레드.
- 행 클릭 → 회차 상세. **행 본체에 손가락 커서 금지**(D-30) — 주 버튼만.
- 반려안: 좌측 회차 레일(본문 폭 손실), 단계 스테퍼(여러 회차 동시 진행에 불리),
  예측|실측 좌우 대조(시험 전에는 오른쪽이 비어 허전).

#### 회차 상세 — **예측 | 실측 좌우 대조** 채택

```
‹ 목록   정화중 3학년 · 25-2 중간 · D-14
         청사진 █ 문제지 █ 채점 ▓ 실점수 ░
─────────────────────┬──────────────────────
 예측                │  실측
─────────────────────┼──────────────────────
 24문항/100점        │ 실제 25문항/100점
 객18 단2 서4        │ 객18 단1 서6
 하9 중11 상4        │ 하7 중12 상6
 제곱근4 이차함수5   │ 제곱근3 이차함수7
 ─────────────       │ ─────────────
 김○○  88 (80~93)   │ 김○○  —  [입력]
 이○○  74 (66~82)   │ 이○○  —  [입력]
 박○○  — 미응시     │
 엔진 v0.4 · 4회차   │ 잔차 —
```

- **보정 루프가 화면 골격 그 자체**다. 예측이 얼마나 맞았는지가 항상 보인다.
- 상단 4단계 띠는 계기판과 **같은 문법**을 유지한다(§8.2 규칙).
- 시험 전에는 오른쪽이 비어 있다 — 비어 있는 것이 정상 상태임이 드러나야 한다.
- 예상 점수는 **점 하나가 아니라 구간**으로 적는다(`88 (80~93)`). 11 §3 L4·§4 —
  관리 지표는 "±N점"이 아니라 **구간 적중률**이다.
- 반려안: 세로 섹션 스크롤(대조 약함), 학생 표 중심(청사진이 묻힘), 좌측 단계 사이드바(본문 폭 손실).

#### 예측 문제지 지면 — **배점 표기함** `[확정 — 2026-08-15]`

- 문항마다 실제 내신처럼 배점(3.2점·4.5점 등)을 지면에 찍는다.
  학생이 실전처럼 시간·배점을 배분하는 연습이 되고, 예상 점수도 배점 기반으로 나온다.
- ⚠️ **D-28의 범위 제한**: 일일/확인테스트 지면은 **종전대로 배점 없음**을 유지한다.
  배점 표기는 **'오늘의 시험'의 예측 문제지에만** 적용되는 예외다.
  인쇄 코드를 전역으로 바꾸지 말 것.

#### Hi-fi `[확정 — 2026-08-16 T7.0]`

이 탭에만 새로 생기는 세 요소를 **G2 4색으로 먼저 읽히게** 한다.
훑는 속도가 최우선인 화면이기 때문이다.

| 요소 | 표현 |
|---|---|
| **신뢰도** | **행 좌측 5px 인셋 바** — 높음 그린 / 보통 옐로 / 낮음 레드. 숫자와 근거 회차를 본문에 병기 |
| **파이프라인 단계** | **색 점(7px) + 라벨, 점이 앞**. 완료 그린 / 진행 블루 / 대기 무색 |
| **예측 구간** | **연속 막대 + 눈금**(폭 132px). 회색 구간 위에 점추정을 2px 세로 눈금으로. 옆에 `80~93` 병기 |
| **잔차** | 구간 **안** 그린 `+3 적중` / **밖** 레드 `−13 빗나감` |

🔴 **인셋 바의 뜻은 탭마다 다르다 — 반드시 지킬 것.**

| 탭 | 좌측 인셋 바 |
|---|---|
| 오늘의 수학 | **"지금 할 일"** (블루 5px, hot 카드) — §8.4 |
| 오늘의 시험 | **신뢰도** (그린/옐로/레드 5px) |

혼동을 막으려고 **오늘의 시험의 인셋 바에는 블루를 쓰지 않는다.**
