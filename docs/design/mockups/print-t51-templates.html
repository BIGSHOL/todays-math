1. 정답: 4
2x − 3 < 7 → 2x < 10 → x < 5. 조건을 만족하는 정수는 문항 보기에 따라 4.
2. 정답: x ≤ 2
−2x ≥ −4. 양변을 −2로 나누면 부등호가 바뀌어 x ≤ 2.
3. 정답: 50g
소금 20g 고정. 20 / (200 + w) = 0.08 → w = 50.
4. 정답: −3 < x < 7
|x − 2| < 5 → −5 < x − 2 < 5 → −3 < x < 7.
